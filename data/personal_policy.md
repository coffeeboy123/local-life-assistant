# 개인 생활 규칙 문서

## 1. 조교 수업 관리

### 1-1. 수업 준비
- 매주 화요일에 MATLAB 실습 수업을 준비한다.
- 수업 내용은 학생들이 따라오기 어렵지 않도록 단계별로 구성한다.
- 실습 코드는 수업 전에 직접 실행해보고 오류가 없는지 확인한다.
- 수업을 준비하면서 새로 배운 내용은 블로그에 정리한다.
- 매주 수요일 오후 1시 30분 수업 시작 전에 코드와 PPT 자료를 이클래스에 업로드한다.

### 1-2. 보강 관리
- 휴강으로 인해 e-보강을 진행할 때는 이클래스 공지로 안내한다.
- e-보강 공지에는 수업명, 보강 대상 날짜, 수강 기간, 동영상 링크 또는 위치를 포함한다.
- e-보강 수강 여부를 확인하고 출결을 체크한다.
- e-보강 동영상을 만들 때는 e-보강 운영 규칙을 먼저 확인한다.

### 1-3. 시험 관리

#### 시험 준비물
- 시험지와 이면지를 넉넉히 준비한다.
- 이면지가 필요한 학생이 있을 수 있으므로 여분을 따로 챙긴다.
- 시험 시간 표시를 위해 빔프로젝터 또는 화면에 시간을 띄울 준비를 한다.

#### 시험 시작 전 안내
- 학생들이 서로 떨어져 앉도록 안내한다.
- 출석을 부른다.
- 시험 시작 전까지 시험지를 덮어놓고 기다리도록 안내한다.
- 시험 문제가 하나인 경우, 문제 수를 미리 설명한다.
- 책상 위에는 필기구만 둘 수 있다고 안내한다.
- 답안 작성 시 볼펜, 샤프, 연필 사용이 가능하다고 안내한다.
- 전자기기(계산기, 핸드폰, 스마트워치 등)는 끄거나 소리가 나지 않게 해서 가방에 넣도록 안내한다.
- 공부하던 자료는 시험 시작 전에 모두 집어넣도록 안내한다.

#### 시험 중 안내
- 시험 시간은 1시간이며 중도퇴실은 불가하다고 안내한다.
- 답은 시험지에 작성해야 한다고 안내한다.
- 이면지는 채점하지 않는다고 안내한다.
- 이면지에도 학번과 이름을 작성하도록 안내한다.
- 이면지가 더 필요한 경우 말하라고 안내한다.
- 시험 중 남은 시간을 확인할 수 있도록 화면에 시간을 띄워둔다.

#### 시험 종료 후
- 시험지와 이면지를 모두 걷는다.
- 제출된 시험지와 이면지 수량을 확인한다.

## 2. 메일 작성 규칙

### 2-1. 교수님께 메일 보낼 때
- 첫 문장은 정중한 인사로 시작한다.
- 본문에는 본인 소속, 이름, 요청 사항을 명확히 작성한다.
- 요청 사항은 너무 돌려 말하지 않고 구체적으로 쓴다.
- 마지막에는 감사 인사를 포함한다.
- 너무 긴 문장보다는 짧고 명확한 문장을 사용한다.

### 2-2. 외부 담당자에게 메일 보낼 때
- 요청받은 자료를 첨부했는지 확인한다.
- 첨부 파일명을 본문에 언급한다.
- 연락 가능한 이메일 또는 전화번호가 필요한 경우 함께 적는다.
- 상대방이 바로 이해할 수 있도록 배경, 요청, 확인 사항 순서로 작성한다.

## 3. 논문 제출 체크리스트

### 3-1. 제출 전 확인 사항
- 제목, 저자명, 소속 정보를 확인한다.
- Figure 번호와 본문 참조 번호가 일치하는지 확인한다.
- Table 번호와 본문 참조 번호가 일치하는지 확인한다.
- Reference 중복 여부를 확인한다.
- 약어는 첫 등장 시 full name과 abbreviation을 함께 작성한다.
- 캡션 문체와 논문 전체 문체가 일관적인지 확인한다.
- PDF로 변환한 뒤 그림, 표, 수식이 깨지지 않았는지 확인한다.
- 제출 마감 시간과 제출 사이트 요구 형식을 확인한다.

## 4. 연구실 생활 체크리스트

### 4-1. 코딩테스트 공부
- 매일 2시간씩 코딩테스트를 공부한다.
- 문제를 풀 때 바로 답을 보지 않고 먼저 스스로 접근 방법을 생각한다.
- 막히면 GPT에게 정답을 바로 묻기보다 힌트를 조금씩 받아가며 해결한다.
- 알고리즘 개념은 유튜브 강의나 글을 참고하고, 직접 정리하면서 공부한다.
- 틀린 문제는 왜 틀렸는지 기록하고 나중에 다시 푼다.

### 4-2. 연구실 출결
- 연구실에는 12시 전에 출근한다.
- 출근 후 교수님께 출근 메일을 보낸다.
- 지각한 경우 지각한 시간의 2배를 주말에 보충한다.
- 부득이하게 늦거나 결석해야 하는 경우 미리 연락한다.
